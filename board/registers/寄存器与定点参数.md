# 寄存器映射与定点参数说明（Dehaze IP v2.0）

> 依据：`驱动源码/xdehaze_hw.h`（IP 自动生成，已随包提供）+ `01_源码/dehaze.cpp`、`inspection_config.hpp`
> AXI-Lite 控制器由 `#pragma HLS INTERFACE s_axilite ... bundle=CTRL` 生成

---

## 一、AXI-Lite 寄存器映射

基地址由 Vivado 地址编辑器分配，下列为**偏移量**。

| 偏移 | 宏（`xdehaze_hw.h`） | 名称 | 访问 | 说明 |
|---|---|---|---|---|
| `0x00` | `XDEHAZE_CTRL_ADDR_AP_CTRL` | `AP_CTRL` | R/W | bit0 = ap_start，bit1 = ap_done，bit2 = ap_idle，bit3 = ap_ready |
| `0x04` | `XDEHAZE_CTRL_ADDR_GIE` | `GIE` | R/W | 全局中断使能 |
| `0x08` | `XDEHAZE_CTRL_ADDR_IER` | `IER` | R/W | ap_done / ap_ready 中断使能 |
| `0x0C` | `XDEHAZE_CTRL_ADDR_ISR` | `ISR` | R/W | 中断状态，写 1 清零 |
| `0x10` | `XDEHAZE_CTRL_ADDR_CTRL_REG_DATA` | **`ctrl_reg`** | R/W | 功能控制，32 位，见 §1.1 |
| `0x18` | `XDEHAZE_CTRL_ADDR_THRESHOLD_REG_DATA` | **`threshold_reg`** | R/W | 算法参数，32 位，见 §1.2 |

---

### 1.1 `ctrl_reg`（0x10）完整位域

| 位 | 名称 | 含义 | 默认（写 0 时） |
|---|---|---|---|
| `[0]` | `DEHAZE` | 去雾使能。0 = 整条链路旁路，原样输出 | 0 |
| `[1]` | `SOBEL` | 边缘检测使能 | 0 |
| `[2]` | `OVERLAY` | 仅 ctrl[1]=1 时有效。1 = 边缘叠白，0 = 输出灰度边缘图 | 0 |
| `[3]` | `PROTECT` | 近白 / 过曝保护，命中时该像素不做去雾 | 0（关闭） |
| `[4]` | `AUTO_A` | 自动估计大气光 A（每帧更新一次） | 0（用固定 A） |
| `[5]` | `RESET_A` | 丢弃历史 A，重新用寄存器值作初值 | 0 |
| `[6]` | `LIMIT_GAIN` | 增益上限钳位使能 | 0（关闭） |
| `[7]` | — | 保留 | — |
| `[15:8]` | `GAIN_Q44` | 增益上限，Q4.4 定点 | **0 → 48**（= 3.0×） |
| `[23:16]` | `BRIGHT_MIN` | 近白保护亮度阈值 | **0 → 224** |
| `[31:24]` | `CHROMA_MAX` | 近白保护色度容差 | **0 → 24** |

`GAIN_Q44` 的三段规则（`inspection_config.hpp:20`）：

```cpp
q = (ctrl >> 8) & 255;
q == 0  → 48      // 3.0×
q < 16  → 16      // 1.0×，等价于不去雾
其余    → q       // 实际倍数 = q / 16，最大 255/16 = 15.9×
```

> 内部用法是 `limit = gain_q4(ctrl) << 4`，即把 Q4.4 换算成与 `gain` 同量纲的 Q8 值。48 << 4 = 768。

---

### 1.2 `threshold_reg`（0x18）完整位域

| 位 | 名称 | 含义 | 写 0 时默认 | 合理范围 |
|---|---|---|---|---|
| `[7:0]` | `OMEGA` | 去雾强度 ω，8 bit 定点（217 ≈ 0.848，230 ≈ 0.898） | **230** | 128 ~ 255 |
| `[15:8]` | `T_MIN` | 透射率下限 t_min（越大越保守，去雾越弱） | **26** | 16 ~ 128 |
| `[23:16]` | `A` | 大气光 A | **200** | 100 ~ 250 |
| `[31:24]` | `EDGE_TH` | 仅 sobel 用，边缘判定阈值 | **80** | 16 ~ 254 |

> ⚠️ **所有字段写 0 都会退回默认值**，无法把某个参数设成真实的 0。这是刻意设计（软件初始化不必知道默认值），但也意味着"把 A 设为 0"这种操作做不到。

> ⚠️ **omega 有两套值**：寄存器写 0 → 230；用 `GENTLE_PARAMS` 预设 → 217。两者去雾强度差 6%，配置时注意统一。

---

### 1.3 推荐配置

| 场景 | `ctrl_reg` | 说明 |
|---|---|---|
| 只跑通看画面 | `0x00000001` | 仅开去雾，**无过冲保护**，大雾会推白 |
| **推荐起始值** | **`0x00000049`**（=73） | 去雾 + 近白保护 + 增益限幅 |
| 加自动估 A | `0x00000059`（=89） | 在 73 基础上开 AUTO_A |
| 只用边缘检测 | `0x00000002` | 不开去雾 |

`threshold_reg` 统一写 `0x00000000`（走默认 200 / 26 / 230 / 80）。

> ✅ `ctrl_reg[3..6]` 四位**均有独立 C 仿真用例**（csim 16/16 全 PASS）：
>
> | 位 | 用例 | ctrl 值 | 验证内容 |
> |---|---|---|---|
> | bit3 PROTECT | `dehaze_protect` | 9 | 近白/高光像素 gain=256，原样保留 |
> | bit6 LIMIT_GAIN | `dehaze_limit_gain` | 65 | gain 被钳到 768（3.0×） |
> | bit4 AUTO_A | `auto_a_frame1_seed` | 17 | 第 1 帧用的是 seed A=200 |
> | bit4 AUTO_A | `auto_a_frame2_evolved` | 17 | 第 2 帧用的是演化后的 A=196 |
> | bit5 RESET_A | `auto_a_reset` | 49 | A 被拉回 200，输出回到第 1 帧 |
>
> ⚠️ 但 **ctrl=73 与 ctrl=89 这两个组合值本身没有单条用例**（它们分别是 `9|64` 与 `9|64|16` 的叠加，各字段已分别验证）。v2.0 上板时具体用的 ctrl 值没有留档，现场若要改 ctrl，建议按 `1 → 73 → 89` 逐步加码对比。

## 二、算法定点规则

### 2.1 完整计算链（与源码逐行对应）

```
① 暗通道        dark  = min over 3×3 of min(R,G,B)          // dark_window
② 尺度因子      scale = (reciprocal_a[A] × ω + 108) / 217
                reciprocal_a[i] = (55552 + i/2) / i          // ≈ 217×256/i
                化简后 scale = 256×ω/A
③ 衰减          attenuation = dark × scale
④ 透射率        t = 255 − (attenuation >> 8)
                t = clamp(t, t_min, 255)
⑤ 增益          gain = reciprocal_t[t] = (65280 + t/2) / t   // ≈ 255×256/t
⑥ 限幅          if (ctrl[6] && gain > limit) gain = limit
⑦ 保护          if (ctrl[3] && ((lo>=bright && spread<=chroma) || hi>=250)) gain = 256
⑧ 恢复          J_c = A + ((I_c − A) × gain) >> 8
                J_c = clamp(J_c, 0, 255)
```

对应源码位置：②④ 在 `dehaze.cpp:141`、③~⑤ 在 164–167、⑥⑦ 在 168–171、⑧ 在 `recover()`（37–43 行）。

### 2.2 位宽约定

| 变量 | 类型 | 位宽 | 依据 |
|---|---|---|---|
| `dark` / `t` / `A` / `omega` | `ap_uint<8>` | 8 | 像素域 |
| `scale` | `ap_uint<17>` | 17 | 最大 `55552×255/217 ≈ 65,280`，17 位够 |
| `attenuation` | `ap_uint<25>` | 25 | `dark(8) × scale(17) = 25` |
| `gain` / `limit` | `ap_uint<16>` | 16 | 最大 `gain = 65280`（t=1 时） |
| `d = I_c − A` | `ap_int<10>` | 10（有符号） | 范围 −255~255 |
| `product = d × gain` | `ap_int<26>` | 26（有符号） | 最大 `255 × 65280 ≈ 16.6 M`，25 位够，留 1 位余量 |
| `value` | `ap_int<19>` | 19（有符号） | `A(8) + product>>8(18)` |

### 2.3 关键定点常数

| 常数 | 值 | 含义 |
|---|---|---|
| `55552` | 217 × 256 | `reciprocal_a` 表的缩放基准 |
| `65280` | 255 × 256 | `reciprocal_t` 表的缩放基准 |
| `217` | — | `scale` 计算中的归一化分母（**魔数，勿改**） |
| `108` | 217/2 | 四舍五入补偿 |
| `256` | — | Q8 定点的小数位 |

**两条倒数表的完整规则**（`dehaze.cpp:9-16`）：

```c
#define K(i) (unsigned short)((65280u + (i)/2u)/(i))
#define A(i) (unsigned short)((55552u + (i)/2u)/(i))
static const unsigned short reciprocal_t[256] = {TABLE(K)};
static const unsigned short reciprocal_a[256] = {TABLE(A)};
```

`(65280 + i/2) / i` 是 `round(65280/i)` 的整数写法，编译期展开成 256 项常量表，综合成 ROM。

## 三、参数锁存与生效时机

| 参数 | 读取位置 | 生效时机 |
|---|---|---|
| `ctrl[0..6]`、`gain / bright / chroma` | `dehaze_core()` 入口 | 本帧 |
| `A` / `t_min` / `omega` / `edge` | `restore_stream()`、`sobel_core()` 入口 | 本帧 |
| `previous_a`（自动 A 的状态） | `static`，跨帧保持 | 帧末更新 |

⚠️ 但 `HLS 200-616` 警告指出：**AXI-Lite 参数经 DATAFLOW 内部 FIFO（深度 2/3）分发**，若在处理过程中连续改参数，可能出现"第 N 帧用第 N−1 帧参数"。**改参数前请先等 `ap_idle = 1`。**

## 四、启动约束（关键）

`return` 使用 `s_axilite bundle=CTRL`，**顶层没有 ap_start 端口**，启动只能通过 AXI-Lite `0x00` bit0 写入。

综合报告的 `Interval(min) = 921,606` 略小于 `Latency(min) = 931,125`，说明 DATAFLOW 三级内部有重叠；协同仿真实测 `Interval(min) = 921,644`（= 一帧像素数 921,600 + 启动开销），即**每次调用只处理一帧，帧与帧不重叠**。

### 4.1 裸机伪代码

```c
#define BASE 0x43C00000   // 以 Vivado 地址分配为准

Xil_Out32(BASE + 0x10, 0x49);                    // ctrl = 73：去雾+保护+限幅
Xil_Out32(BASE + 0x18, 0x00000000);              // 参数走默认 200/26/230/80

while (1) {
    // 等空闲，避免参数在途
    while ((Xil_In32(BASE + 0x00) & 0x4) == 0) { }

    Xil_Out32(BASE + 0x00, 0x1);                 // ap_start
    while ((Xil_In32(BASE + 0x00) & 0x2) == 0) { }  // 等 ap_done
}
```

### 4.2 自动估 A 的用法

```c
Xil_Out32(BASE + 0x10, 0x59);   // = 89：73 + AUTO_A

// 第 1 帧用阈值寄存器里的 A 作为初值（写 0 则用 200）
// 之后每帧末尾更新一次，单帧最多变 ±4，收敛约 10 帧

Xil_Out32(BASE + 0x10, 0x79);   // 0x59 | 0x20：置 RESET_A
Xil_Out32(BASE + 0x10, 0x59);   // 清 RESET_A
```

> 注意：`count < 16` 时（采样点太少）本帧**不更新 A，静默沿用旧值**，没有状态位可以查询。

## 五、给软件侧的对接约定

1. **不要写 `ctrl = 1`** 直接上大雾图 —— 这是无过冲保护的裸模式，`t_min=26` 时偏差被放大 9.81 倍，亮区会整片截白。先用 73。
2. **写 0 等于用默认值**，不能把参数设成 0。要"关掉去雾"请用 `ctrl[0]=0`，不是把 A 设 0。
3. **改参数前等 `ap_idle`**，否则可能错帧。
4. **帧长固定 921,600 像素**，DUT 不校验 TLAST。VDMA 少给或多给一个像素，画面会永久错位且不报错。
5. **寄存器偏移不要改**（0x10 / 0x18），后续算法迭代保持兼容。
